Eigenius sits at the intersection of three traditions. The
typed-knowledge-graph machinery descends from the dependently-typed
calculi pioneered by Coq, Lean, and Agda; the four-warrant
taxonomy is a chain-instantiated form of Artemov's justification
logic; the modular dispatch architecture borrows from
Goguen-Burstall institution theory. This section collects the
papers that present the framework academically, along with the
citation anchors and the recommended reading order for someone
coming from each tradition.

## Papers

<PaperGrid />

The monograph develops the theory in full, and the
[EigeniusTheory](https://github.com/eigenius/theory) library
formalizes it in Lean 4. The LICS paper, in preparation, presents
the theory at conference length. The arXiv preprint describes the
system built on it.

## How to cite

For the type theory, the justification logic, the institutions, or
the knowledge-graph theory, cite the monograph. The DOI always
resolves to the current version on Zenodo:

```bibtex
@book{Will2026Eigenius1,
  author    = {Will, Hans-Martin},
  title     = {Typed Knowledge over Constructive Institutions},
  series    = {Eigenius},
  volume    = {I},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23884679},
  url       = {https://doi.org/10.5281/zenodo.23884679},
}
```

For the system architecture — epistemic stratification,
institutions as integration boundaries, content-addressed storage —
cite the arXiv preprint:

```bibtex
@misc{will2026eigenius,
  author        = {Will, Hans-Martin and Brown, Jr., Allen L. and Fuchs, Matthew},
  title         = {Eigenius: A Typed Knowledge-Graph {DBMS} with Epistemic
                   Stratification and Institution-Mediated Reasoning},
  year          = {2026},
  eprint        = {2608.04457},
  archivePrefix = {arXiv},
  primaryClass  = {cs.DB},
  doi           = {10.48550/arXiv.2608.04457},
  url           = {https://arxiv.org/abs/2608.04457},
}
```

For a specific result you have re-run, cite the repository with the
commit hash — or, better, the content-addressed chain state, which
pins the exact inputs rather than a repository snapshot:

```bibtex
@misc{eigenius2026,
  author       = {The Eigenius Authors},
  title        = {Eigenius: a typed knowledge graph for
                  auditable scientific reasoning},
  year         = {2026},
  howpublished = {\url{https://github.com/eigenius/eigenius}},
}
```

## Reading order, by background

The [monograph](/research/papers/typed-knowledge-over-constructive-institutions/)
covers the theory end to end, and the
[preprint](https://arxiv.org/abs/2608.04457) covers the architecture
end to end; this site and the repository go deeper on any one piece
of the implementation. By tradition:

**From type theory** (Coq, Lean, Agda, dependent types):
start with Chapter 2 of the monograph. It defines the kernel type
theory, where proof irrelevance is a provable fact with an explicit
witness rather than a rule of conversion, and proves its metatheory;
Chapter 6 gives the checking procedures. The Lean modules
`EigeniusTheory.TypeTheory` and `EigeniusTheory.Checking` formalize
both. The [ESL chapter §6 — Resources, types, and the
layer](/docs/esl/06-resources-types-and-the-layer/) is the bridge
between the resource graph and the type system.

**From justification logic** (Artemov, modal calculi):
Chapter 3 of the monograph develops a justification logic over the
kernel's propositions, with evidence, support, and provenance
semirings (`EigeniusTheory.Justification` in Lean). The
[Justification logic page](/concepts/justification-logic/)
is the bridge from Artemov's calculus to the chain-resident
form. The four-warrant taxonomy is the chain instantiation; each
`JustifiedBy` constructor in the reasoning institution's
inductive type maps to one of Artemov's evidence-bearing
modalities.

**From institution theory** (Goguen–Burstall, Meseguer):
Chapter 4 of the monograph organizes the theory of an environment
as an institution: extending the store is a signature morphism, and
a verdict from an external system enters along a comorphism
(`EigeniusTheory.Institutions` in Lean). For the implemented
surface, read [ESL §9 — Institutions](/docs/esl/09-institutions/)
and the [composition guide](/docs/composition/).

**From provenance and FAIR / ALCOA+**:
the [Drug-screening example](/examples/drug-screening/) is the
canonical end-to-end illustration. The chain delivers most of
the ALCOA+ enumeration structurally; the verifier closes the
*accurate* principle by deterministic re-execution rather than
by author attestation.

**From AI / ML systems**:
the [Concepts overview](/concepts/) frames the chain as the
substrate for inspectable AI reasoning. The kernel is "a
compiler for AI thought" — agents must produce typed proof terms
the type-checker admits; hallucinations either fail to commit or
land visibly as `Declared` artifacts with the agent on record.
The [Domain bridges page](/concepts/domain-bridges/) is the most
direct illustration of how the type discipline blocks the most
common AI failure mode (unjustified cross-vocabulary leaps).
